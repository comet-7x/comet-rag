# 第二十九批：完整复杂 PDF 的原生页事实

在独立 MinerU 3.4.5 文档 API 的可选部署扩展下，完整 NIST SP 800-145 / 800-144
分别获得物理页 1–7 / 1–80。图片、HTML 表格、列表及跨页正文均通过原生全文重建、
规范化和 page 分块硬边界检查。本批补齐这个指定部署模式的完整复杂页验证，**不等于
上游已内置此 HTTP 功能，也不关闭独立标签、固定权重或目标生产部署门禁。**

## 上游核查与方案选择

| 路径 | 核查结果与决定 |

## 最小协议和物理页约束

完整安装、wire contract、范围与回退见[独立部署说明](../../deploy/mineru/README.md)。
保留 protocol v2、原端点和原请求参数，增加健康声明
`extensions.comet_page_markdown=1` 与结果的同名版本化对象，包含 version、
boundary_mode、page_count 和逐页 page_idx/markdown。它是明确 namespaced 的
Comet 部署扩展，未伪装成上游官方字段。

消费者只在单次 health 协商成功且 backend=vlm-http-client 时启用；协商值在本次
上传、轮询、重提间传递，不修改共享适配器状态。此模式关闭冗余 content list 回传，
保留总超时、流式响应上限和 Markdown 上限。整数拒绝 bool/float，页号完整连续，空页
保留在 wire 中，页对象保留非空页的原物理编号；非空片段必须逐字重建全文。声明能力
后字段丢失或校验失败明确报协议错误，不静默退回 section。未声明的服务保持旧路径。

仅有完整重建仍不足以证明页归属：上游会跨页合并引用列表或表格，把后一页内容搬到
前页。部署扩展要求显式关闭跨页表格合并，并逐页调用原生段落后处理，再调用同一
渲染函数。拒绝残余 cross_page span 及被跨页表格合并删除的 body；允许合法同页
文本合并。每次渲染只复制当前页，避免上游规范化 span 时污染后续产物。

用实际 3.4.5 finalize/merge 函数验证两个物理页的引用列表：逐页处理保持每页各一项；
故意调用全局 merge 后变成前页两项、后页零项，移动标记守卫明确拒绝。此反例说明
“能拼回全文”与“物理页可信”必须分别验收，未放宽旧投影来强行通过复杂样本。

部署工件仅在 `deploy/mineru/`，不进 wheel。安装前验证版本与三个上游文件摘要，
再在临时目录应用补丁并做语法检查；写入失败恢复原文件。三个摘要与官方 release
字节一致。最终安装器从干净源码生成的四个文件与本轮实际运行环境逐字节一致。
摘要守卫是补丁兼容检查，不等于完整依赖/权重锁定，也不保证多文件断电事务。

## 完整公开 PDF 结果

仍使用[原始来源锁](../../evals/pdf/pages.json)中的两份完整 PDF，不拆页、不重新排版，
不提交二进制或原生模型输出。来源、许可和原始文件核验沿用第二十七批。

Republished courtesy of the National Institute of Standards and Technology.

| 输入 | 首轮成功核验 | 全量集成严格核验 | 实际非空物理页 | 全量规范化字符 |
|---|---:|---:|---:|---:|
| SP 800-145，完整7页 | 8.04s | 8.07s | 1–7，7页 | 10,054 |
| SP 800-144，完整80页 | 115.34s | 115.70s | 1–80，80页 | 220,910 |

两轮都保留原始输出。80页首轮为220,913字符；不挑最好一轮，也不把3字符变化归因于
未经确认的因素。耗时为单次wall time，不是p95、吞吐或外部服务CPU/GPU/RSS测量。

逐页检查还包括：800-145物理页2的图片链接、页4勘误HTML表格、页6的PaaS段末尾与
页7的继续段；后半段没有被归入页6。800-144的表2位于**物理页52**，而非印刷页42；
标题与HTML表格均落在该物理页。入库/检索用例仍使用常量embedding，只验解析链路；
独立页核验不访问生产索引或中间件。完整PDF集成显式要求页事实，section回退不能通过。

上游Markdown仍可能错字或不包含脚注；页一致不表示PDF全部语义完整，也不保证长表
在一个chunk内。本批没有按作者金标修正文、默认改变chunk窗口或用旧pypdf字符span
评分原生输出。独立复核与固定工件不到位前，不重跑一个语义无效的排名对照来报高分。全扫描长文、
中文多栏和真正跨页长表仍需专门样本；本批没有把87页覆盖解释为所有复杂版式通过。
