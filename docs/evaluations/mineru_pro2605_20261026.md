# MinerU2.5-Pro-2605 补验

2026-10-26。结论：指定服务可用于现有提取链路。两轮主实验只将既有上游URL端口
替换为9919、模型名替换为 `opendatalab/MinerU2.5-Pro-2605-1.2B`，未升级解析器、
修改应用代码或默认配置。新增图像解读明显，但背封遗漏未解决，不据单份PDF批准生产质量。

## 上游与实验范围

官方[模型卡](https://huggingface.co/opendatalab/MinerU2.5-Pro-2605-1.2B)说明2605针对
2604改进布局分类和图像分析；[官方更新记录](https://github.com/opendatalab/MinerU/blob/master/docs/en/reference/changelog.md)
记录该模型升级。这里比较的是旧2509服务与用户提供的2605服务，不将官方2604对照
数字移作本项目成绩。新旧端点的 `/v1/models` 均可用，新端点声明的模型名正确，
但没有返回权重/tokenizer不可变字段，实际工件身份仍unknown。

沿用独立MinerU3.4.5、既有逐页扩展v1、vlm-http-client、并发2、关闭跨页表格合并等
原参数。9919属于上游VLM；应用提取器继续连接本次自建文档API，不能将模型端口
误填为应用文档服务地址。没有启动生产Context或写入向量索引。

同一用户工作区PDF副本60页、9024767字节，SHA-256
`e42f3b70cee6344ca8e0cb06ccc4028e56a05266cbd331c9e008fe05e62a2ffe`，每轮前后核验。
参考探针来自前轮原PDF自审：13项文本关键词、表1的表头与24个数值单元、背封3项文字。
图表另作代表页目视检查，未新增独立人工金标，也没有复用旧正文span做新检索评分。

## 新能力与引用边界

在完全相同主参数下，Pro两轮各新增43个 `<details>` 图像说明块，长度分别18746/
26344字符。原PDF第22页的柱图现在产生近似值表格；对照原页能确认它对应图6，
但输出含近似标记，原图没有逐柱精确数值标签。这是模型读图结果，不是原PDF中逐字
存在的数据表，不能把它当成已人工核准的精确原文证据。

实际安装的上游 `cli/api_request.py` 默认 `image_analysis=True`，VLM路径将该选项
交给原生处理函数。旧模型在该参数下没有同类输出，新模型将其能力体现出来；应用
没有额外开启新开关。两轮全文摘要不同，不能共用canonical或直接迁移旧标签span。

补充诊断直接复用上游原生CLI，不写新的协议客户端：

```bash
/path/to/mineru-env/bin/mineru -p /path/to/source.pdf -o /path/to/new-output \
  --api-url http://127.0.0.1:28989 -b vlm-http-client --image-analysis false
```

该次输出没有 `<details>`，事实和表格探针保持通过，背封仍缺失。CLI语言默认ch，
VLM分支不消费该语言参数；此任务单列诊断，不混入仅两项切换的主对照或速度统计。
没有用正则剥离图像说明作为生产方案，也没有复制上游排版器。

诊断的上游middle JSON进一步给出：物理60页的para_blocks为空，8个块全部进入
discarded_blocks、类型均为footer，3项目标文字却都存在于这些被丢弃块内。因此该次
不是文字完全没识别，而是分类/过滤后未进入Markdown。主实验没有请求middle JSON，
不把这次诊断外推成所有轮次的已证实根因；处理位置应优先审查上游布局及页眉页脚
保留策略，不在Comet中猜测恢复正文。聚合记录保留块类型与探针存在性，不公开原文。

## 验证、产物与采用建议

现有消费者、逐页部署和原生页审计的134项定向单测通过；真实PDF共完成两轮默认
分析和一轮关闭分析诊断。没有代码改动，不把上一轮300条集成或3632条单测冒充本次
新运行。原始PDF、响应、对照探针和脚本在Git忽略目录
`.artifacts/v2-validation/mineru-pro-2605-20261026/`，仓库只保存
[不含用户正文的聚合数字](mineru_pro2605_20261026.json)。项目 `.env` 字节保持不变。

可以使用新模型；采用前应明确是只要OCR正文，还是让模型图像解读也进入检索和引用。
前者优先复用上游已有选项；后者需要区分派生解读与原文证据，保留近似/不确定性，
重新冻结标签及核验新命名空间，不能直接复用旧索引和span。本次保持生产默认不变，
独立人工及固定模型工件门禁继续保留。独立API在任务排空后停止，未操作服务器模型进程。
