## 解析、权重与 token 的证据边界

现有MinerU地址 /health返回404，且不符合其非回环TLS契约；没有上传PDF，也没有把
pypdf接成生产fallback。当前测的是独立参考提取后既有normalizer/page/索引/检索链路，
不代表真实MinerU协议或其页事实通过。完整生产解析仍需正确的protocol v2配置。

两个模型及其原生/tokenize可用：Qwen/Qwen3-VL-Embedding-8B（4096维）和
Qwen/Qwen3-VL-Reranker-8B；/models未给权重或tokenizer revision，继续unknown。
服务报告max_model_len=40960，只是部署声明，不当成已验收的模型极限。模型名称不
等于权重锁。部署方需提供两模型权重、tokenizer/chat template、服务版本、dtype/量化、
截断/池化/指令配置和硬件的不可变身份；调用方model_revision字符串不构成远端证明。

[vLLM官方可复现性说明](https://docs.vllm.ai/en/latest/usage/reproducibility/)也区分种子、
调度/批次、硬件与版本条件。本项目没有证明当前服务开启哪种确定性设置，不能将本次
排名波动归因于某个特定内核或批处理行为，也不能认为固定权重就自动保证逐位相同。

正文预算直接使用服务的raw-text token序列计数，验证count与序列长度、整数类型及
正文SHA一致；不自行实现tokenizer，不按字符换算。起止多语言探针相同，只证明这几个
探针的观测行为，不能证明tokenizer工件或权重固定。

512/1024预算是**指定reranker tokenizer下，各返回正文独立编码的token数之和**。
只取原排序完整前缀，首个超额块即停止；不跳过大块找后面的短块，不切正文、不改引用
区间。预算投影没有再次召回或重排，清除原search时延，不冒充实测预算检索。
计数采用/tokenize(prompt=正文)的默认行为，独立prompt默认添加的token按实际结果计入。
未纳入联合请求的query、指令、chat template等额外开销及潜在截断；不等于
embedding/rerank推理成本，也不等于另一个生成模型的上下文预算。三组探针在默认、
add_special_tokens=false/true下IDs相同；这不是全输入无特殊token或开关一定被服务端
采用的证明，不能用少数探针补齐工件/配置身份。

## 冻结对照与最终结果

[冻结设计](../../tasks/v2_pdf_evaluation_design.md)规定独立InMemory，hybrid、top_k5、
fetch_k50（每路），child800/overlap80/parent1600字符。比较recursive、page、hierarchy
child/parent及重排开关，共8组/192次search；16组预算投影不重复调用模型。
各组独立建索引/召回，不是冻结候选池的因果实验，不能把组间差异全部归因于重排。
融合候选最多61个；索引child数为62/65/67，hierarchy另存35个parent。所有页策略和
层级返回均复核落在单一真实物理页内，父子span与原文一致。

## 重复观测与工具修正

保留两轮较早完整观测，不覆盖原始run。其中一次在强化来源核验前，一次在范围标签
纠正前；原始数据/标签指纹相同，早期误标synthetic corpus的settings保持原样以便追溯。
最终全组重测使用正确PDF reference scope和最终源码；没有把早期分数冒充最终代码收益。
比较全部指标向量时，两轮早期观测各有15个report与最终不同（含预算投影，非独立样本）。
没有足够证据确定原因，也不选最好一轮。主要结论仍是边界/代价与待复核，而非生产达标。

来源核验器已通过先红后绿复现三处问题：空样本、空页、逆序页都曾被误报核验通过；
现拒绝这些输入。生成器拒绝把PDF来源按Markdown写成.pdf，页标签拒绝跨页单quote。
盲审包区分unreviewed与无答案，预算拒绝bool/错配正文和错误token序列；客户端单例
覆盖整轮并在模型故障、坏计数或探针变化后关闭，不输出健康summary。

8项独立副本反向缺陷分别允许伪PDF生成、跨页证据、泄漏分类、跳过超额块、bool计数、
空核验、绕过page策略、错误正文计数；全部被目标用例检出，无收集/夹具error。
工作区没有注入缺陷。新增28项unit与9项benchmark，后者独立纳入CI，不访问网络/GPU。

完整原始PDF、12页PNG、来源核验、三轮run/report、计数/探针、盲审ZIP和日志保留
`/tmp/comet-v2-batch27-validation/`；不提交PDF二进制、地址/凭据或原始模型结果。
引用/许可与复现命令见 [工具说明](../../evals/pdf/README.md)。M4-T10/H/I仍未关闭。
