# 真实模型检索实测：2026-10-25

本轮完成真实模型服务探测、标签自审和六组独立内存检索实验。结果表明模型协议可用，
并暴露了文档命中指标掩盖标题孤块、关键词混淆实体的案例；小样本高分没有关闭生产质量门禁。

## 配置、服务与隔离边界

- 项目根目录没有 config.yaml；从现有 .env 选取 embedding/reranker 项，在内存构造 APPConfig。
- 服务声明的 ID 分别为 `Qwen/Qwen3-VL-Embedding-8B`、`Qwen/Qwen3-VL-Reranker-8B`。
  /models 返回 ID 一致，但没有可核验权重提交标识，两个模型的权重版本均记为 unknown。
- embedding 的 query/document 探测实际返回 4096 维，数值有限、非零，范数约 1。
  reranker 三个探测候选全部返回有限得分、索引完整；相关段落排第一，得分约 0.9799。
- 相同地址的 /models 对照：两个服务经当前环境代理均为 502，直连均为 200。
  正式实验仅在子进程将配置中的两个 hostname 加入 NO_PROXY，没有修改 .env 或全局代理。
- 只构造模型客户端、共享闸门和独立内存 Store；没有创建完整 Context，也没有连接
  PostgreSQL/Redis/Milvus/MinerU/对象存储，没有新建实际知识库或操作用户资料。
- 以下是 108 次 RetrievalService.search；开启重排的 54 次均观察到 reranked=true，
  关闭组均为 false，无失败、降级、漏查询、旧 revision 或跨 KB 命中。客户端用现有退出栈关闭。

## 结论、复现与未完成项

- 服务协议、维度和有限值检查通过；重排的本次局部收益可追溯到具体查询。
- H 关闭重排已达到本集同样的主要质量指标，不能声称开启重排总能提高质量。
- 两条无答案查询在全部模式均返回内容；没有答案生成链路，不能据此计算幻觉率。
  不从两条样本设阈值，也不将不同阶段/模式的分数当作统一概率。
- 只有 16 条正查询、2 条无答案和极小候选池；标签没有独立复核。没有长文/PDF/
  page/OCR、真实资料分布、ANN/精确召回对照、同 token 预算或部署负载实测。
  M4-T10 与 H/I 保持未完成，默认检索/入库/模型配置均未更改。
